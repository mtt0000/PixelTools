PixelXpert Minimal Config

Enable Clear All Button (Recents)
Adds a 'Clear All' button in the recents view. (Requires reboot)
Disable System Back Gestures
Disables the default edge back gestures. (Applies immediately)
Enable File to Clipboard
Shows 'Copy content in clipboard' in Android share sheet. (Applies immediately)
Enable Kill App Button
Adds a 'Force Stop' option in the recent apps menu. (Requires reboot)
Enable Hide App Feature
Adds a button to hide tasks from the recent apps view. (Requires reboot)
Enable Screenshot Anywhere
Allows taking screenshots in apps that normally block it. (Requires reboot)
